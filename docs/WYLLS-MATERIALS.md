# Wylls の設定登録に必要な資料（質問のまとめ）

Wylls プロジェクトは空の状態で作成してあります。以下を、**承認済みのものだけ「確定」**、検討中のものは「提案」として登録します。
過去資料をまとめて渡す場合は「資料を取り込む」で入れると、すべて提案になります。

## 1. 識別と一言説明（プロジェクト設定）
- 投稿で使うゲーム名の表記（日本語・英語・略称）
- 初見の人向けの一言説明（何をするゲームか）
- 公式リンクのドメイン（サイト・応募フォームなど）
- 既定のハッシュタグ（使う／使わない、何個まで）

## 2. 世界（創作）
- 確定している世界の前提（舞台・時代・ルール）と、検討中の部分の区別
- 固有名詞・用語：正しい表記、読み、英語表記、使ってはいけない旧称・誤表記
- キャラクター：名前・別名・話し方・公開してよいか
- 物語上すでに起きた出来事（投稿済みのものを含む）
- 書いてはいけない設定（矛盾パターンにしたい例：「◯◯は××しない」）

## 3. 表現
- 世界内の語り手は誰か（存在する場合）。一人称・文体・署名・しないこと
- 開発者として話すときの口調（です・ます等）
- 画像の参考：色調・モチーフ・避ける表現、参考にしてよい手持ち画像
- 過去の良い投稿・悪い投稿と、それぞれの理由

## 4. 現実の事実
- 機能ごとの実装状況（公開済み／テスト中／開発中／予定／構想／中止）と、根拠（パッチノート等）
- 投稿に書きたい実績・数値（受賞・提携・賞金・利用者数）と、それぞれの根拠（URL・資料）
- テスト募集の要項（期間・参加方法・条件・報酬の有無）
- 引用してよい実在ユーザーの声（同意の有無）

## 5. 運用
- 外部モデル（Anthropic API など）に送ってよい範囲／送ってはいけない情報
- 絵文字・CTA の方針
