# 整合性チェック：検出できること・見逃し得ること

検査は **登録された正本（設定・事実）と語の一覧に基づく機械的な照合** です。文章の意味を理解して矛盾を判断しているわけではありません。
指摘には必ず「理由」「該当箇所（投稿番号と本文中の位置）」「参照した設定・過去投稿」を付け、ルールごとの限界を画面に表示します。
ルールの一覧と各ルールの限界は `src/lib/checks/catalog.ts`（画面：整合性チェック）にあります。

## 架空プロジェクトでのテスト（`tests/unit/checks.test.ts`）

| 観点 | 検出する例 | 結果 |
| --- | --- | --- |
| 設定矛盾 | 「白海が干上がったのは百年前」（設定は約300年前・矛盾パターン登録済み） | 要修正・参照「白海の干上がり（設定資料 v2）」 |
| 設定矛盾 | 「センは…海を見たと言った」（センは海を見たことがない） | 要修正 |
| 数値の食い違い | 「ミズハには井戸が五つ」（出来事には「三つ」） | 要確認（目安） |
| 廃止設定の混入 | 「塩貨」（廃止。置き換え先「塩札」） | 要修正・置き換え先を提案 |
| 未公開情報 | 「交易商ルカ」（未公開） | 要修正 |
| 誤表記 | 「ハクカイ」 | 要修正・正しい表記を提案 |
| 未実装機能の断定 | 「砂嵐を実装しました」（開発中）、"Guilds are now live"（構想）、オークションハウス（中止） | 要修正・実装状況を表示 |
| 架空の実績 | 「入賞しました」（実績は提案段階で根拠なし）、「5,000人が遊んでいます」、提携、賞金 | 要修正 |
| 根拠のある実績 | 「120名が参加」（根拠つき確定実績） | 指摘なし |
| 存在しない声 | 「テスターからは『最高の交易ゲーム』との声」「大好評」（題名の『塩の街道』は引用と見なさない） | 要修正 |
| 実話風の行動 | 「あるプレイヤーは塩札だけで隊を三つ雇いました」 | 要確認 |
| 重複投稿 | 投稿済みの物語とほぼ同じ本文 | 要修正・元の投稿と共通部分を表示 |
| 語り手の混同 | 世界内の語りに「アップデート」や URL、開発者の語りに語り手の署名 | 要確認 |
| 現実の約束 | 世界内の語りに「報酬が必ずもらえる」（作中の「案内の報酬は塩札二枚」は要確認どまり） | 要修正 |
| 募集要項 | 告知情報にない日付・約束、告知情報の紐付けなし | 要確認／要修正 |

良い例どおりの物語投稿、事実どおりの開発投稿、告知情報どおりの募集投稿では要修正が出ないことも確かめています。

## 既知の見逃し（テストで「検出できない」ことを固定しています）

| 見逃す例 | 理由 |
| --- | --- |
| 「白海から水が消えたのは、つい最近のことだ」 | 数字も矛盾パターンもない言い換え |
| 「七番隊の老いた潮読みは、昔は毎日泳いでいた」 | 名前（セン）を出さずに同じ人物を指している |
| 「砂嵐、もう触れます」 | 断定の言い回しが語の一覧にない |
| 「多くの方に遊んでいただいています」 | 数字も定型句もない誇張 |

このほかに見逃し得るもの：

- 複数の文・複数の投稿にまたがる矛盾（例：1 投稿目で夜、2 投稿目で同じ場面が昼）
- 比喩・皮肉・婉曲表現、主語の省略
- 登録していない設定との矛盾（正本にないことは判定できない）
- 名前の表記揺れのうち、別名・誤表記として登録していないもの
- 英語の言い換え（英語の語彙は最小限）
- 英文と日本語の意味確認が一致しているか（自動では確認しない）
- 画像・動画の中身（写り込み、文字、世界観との整合）
- 他のプロジェクトや、実際の X 上の投稿との重複

## 誤検出し得るもの

- 宣伝文句の一覧の語（「未来」「所有」など）を作中で正当に使った場合
- 数値の食い違い：同じ設定名と同じ単位でも、別のものを指している場合
- 抽象語の目安：意図的な詩的表現

## 「確認済み」の扱い

要修正の指摘は、修正するか理由を付けて「確認済み」にしないと承認できません。理由は承認記録に残り、書き出す Markdown にも件数が載ります。
